# Tangga Kekayaan

Aplikasi web pelacak "6 Anak Tangga Kekayaan": catat pengeluaran, lunasi utang, dana darurat, naikkan penghasilan, investasi rutin, aset produktif.

Satu file `index.html`, tanpa server dan tanpa database. Data tersimpan di browser (localStorage). Pindah perangkat atau buat cadangan lewat tombol **Ekspor data** dan **Impor**.

## Pasang di GitHub Pages
1. Upload `index.html` dan `README.md` ke repository.
2. Settings, Pages, Deploy from a branch, branch `main`, folder `/ (root)`, Save.
3. Buka `https://USERNAME.github.io/NAMA-REPO/`.

Simulasi investasi hanya ilustrasi, bukan jaminan hasil dan bukan nasihat keuangan.
